# Slide Patterns

## General Structure
- **Header**: Action-oriented headline that states the "so what"
- **Body**: Evidence that supports the headline (chart, table, bullets)
- **Source/footnote**: Data source, base size, date

## LHS / RHS Pattern
Use when comparing two things (e.g., current vs. future, us vs. competitor).

```
LHS: Current state / Problem          | RHS: Opportunity / Recommendation
- Bullet with supporting data         | - Bullet with supporting data
- Bullet with supporting data         | - Bullet with supporting data
```

## Implication Slide
Use at the end of a section to land the "so what."

```
Header: [Decisive takeaway]
Body:
  - Key finding 1 → Implication for client
  - Key finding 2 → Implication for client
  - Key finding 3 → Implication for client
Bottom: Recommended next step or decision needed
```

## Evidence Slide
Use when the goal is to stack proof points.

```
Header: [Claim being supported]
Body:
  - Quote / stat 1 (Source)
  - Quote / stat 2 (Source)
  - Quote / stat 3 (Source)
Footer: Source details
```

## Tips
- One message per slide — if you need two, split it
- Charts > tables > bullets (when data allows)
- Label axes, include units, cite the source

# Survey Patterns

## Question Phrasing
- Use simple, neutral language (no leading questions)
- One concept per question (don't double-barrel)
- Specify the time frame when relevant ("In the past 3 months...")
- Use "select all that apply" vs. "select one" explicitly

## Scale Conventions
- Agreement: 5-point Likert (Strongly disagree → Strongly agree)
- Satisfaction: 5-point (Very dissatisfied → Very satisfied)
- Purchase intent: 5-point (Definitely would not buy → Definitely would buy)
- Frequency: anchor with specific periods ("Once a week," "2-3 times a month")
- Always include a "Not applicable / Don't know" option where appropriate

## Logic / Routing
- Document skip logic clearly: "If Q3 = 'No' → Skip to Q7"
- Use consistent numbering (don't renumber after skips)
- Gate awareness before usage, usage before satisfaction

## Module Order (typical)
1. Screener / category behavior
2. Awareness (unaided → aided)
3. Usage / purchase behavior
4. Attitudes / perceptions
5. Concept / stimulus evaluation (if applicable)
6. Demographics

## Tips
- Keep surveys under 15 minutes for consumer panels
- Randomize answer options where order bias is possible
- Pre-test with 2-3 people before fielding
- Flag any question where base < 50 as "directional only"

# Evidence Rules

## Citation Format
Every quote or stat must include:
- **The quote/stat** (verbatim or clearly paraphrased)
- **Why it matters**: 1 sentence on how it supports the point
- **Source**: File name + slide/page number (e.g., `Nielsen_Cat_Review_2025.pdf, p.12`)

## Rules
- Never fabricate or guess a source — if you can't find it, say so
- If paraphrasing, note "paraphrased" and keep it faithful to the original
- Prefer primary sources (original report) over secondary (press coverage)
- When stacking multiple proof points, vary the source types (e.g., syndicated data + expert interview + survey result)

## Source Quality Hierarchy
1. Syndicated data (Nielsen, IRI/Circana, Euromonitor)
2. Company filings / investor presentations
3. Industry reports (McKinsey, Bain, Deloitte, trade associations)
4. Trade press (FoodNavigator, Grocery Dive, etc.)
5. General press (WSJ, FT, etc.)
6. Blogs / social media (use cautiously, flag as anecdotal)

## Quoting in Slides
- Use pull-quote format for impactful verbatims
- Keep quotes short (1-2 sentences max on a slide)
- Attribute clearly: "Category is seeing a structural shift toward value" — Nielsen CPG Report, Q3 2025
